# FPGA Light Sensor Buzzer Controller

VHDL-based FPGA system that converts phototransistor light intensity measurements into discrete buzzer frequencies.

The project implements a custom ADC interface, processes the measured light intensity and generates different buzzer tones depending on the input level.

## Features

- Phototransistor-based light intensity measurement
- ADC serial interface implemented in VHDL
- 16-bit ADC frame reception with a 12-bit output value
- Finite State Machine for ADC communication
- Eight discrete buzzer frequencies
- Automatic tone selection based on measured light intensity
- Hardware buzzer enable/mute using an FPGA switch
- Modular RTL design using separate VHDL components
- Designed for the Artix-7 FPGA platform

## How It Works

The FPGA continuously reads the ADC output connected to the phototransistor.

The `light_sensor` module generates the ADC clock and chip-select signals, receives a 16-bit serial data frame and extracts the 12 least significant bits as the measured ADC value.

The resulting 12-bit value is passed to `buzzer_controller`, where it is converted into one of eight predefined tone frequencies.

The `SW_zero` input provides an additional hardware enable function. When the switch is disabled, the buzzer output is forced low.

## ADC Interface

The `light_sensor` module implements the communication sequence using a finite state machine with three states:

```text
        ┌───────┐
        │ IDLE  │
        └───┬───┘
            │
            ▼
      ┌────────────┐
      │ READ_ADC   │
      └─────┬──────┘
            │
      16 bits received
            │
            ▼
     ┌──────────────┐
     │ UPDATE_OUT   │
     └──────┬───────┘
            │
            ▼
          IDLE
```

The ADC communication uses:

- `ADC_DOUT` — serial data input
- `ADC_CLK` — generated ADC clock
- `ADC_CS` — chip-select signal
- `data_out` — 12-bit converted value

The module uses a 16-bit shift register to receive the complete frame and a counter to track the number of received bits.

## Buzzer Frequency Control

The `buzzer_controller` module converts the 12-bit ADC value into predefined buzzer frequencies.

| ADC Range | Buzzer Output |
|----------:|---------------|
| 0–455 | Off |
| 456–910 | 523 Hz |
| 911–1366 | 587 Hz |
| 1367–1822 | 659 Hz |
| 1823–2278 | 698 Hz |
| 2279–2734 | 784 Hz |
| 2735–3190 | 880 Hz |
| 3191–3646 | 988 Hz |
| 3647–4095 | 1047 Hz |

The selected frequency is generated by counting `Clock100MHz` cycles and toggling the buzzer output when the corresponding counter limit is reached.

This produces a square-wave signal whose frequency depends on the measured light intensity.

## VHDL Structure

The project is divided into three main modules:

```text
src/
├── top.vhd
├── light_sensor.vhd
└── buzzer_controller.vhd
```

### `light_sensor.vhd`

Implements the ADC communication logic.

Main functions:

- ADC clock generation
- chip-select control
- serial data reception
- 16-bit shift register
- bit counting
- FSM-based communication control
- extraction of the 12-bit measurement

### `buzzer_controller.vhd`

Implements the light-intensity-to-frequency conversion.

Main functions:

- conversion of the 12-bit ADC value to an integer
- selection of the corresponding frequency range
- generation of the buzzer square wave
- buzzer silence when the input value is below the first threshold

### `top.vhd`

Integrates the complete system.

Main functions:

- instantiation of `light_sensor`
- instantiation of `buzzer_controller`
- connection of internal signals
- hardware enable/mute logic for the buzzer

## Constraints

The XDC file maps the top-level signals to the FPGA pins and defines the 100 MHz system clock.

Main signals:

| Signal | Function |
|--------|----------|
| `Clock100MHz` | 100 MHz system clock |
| `ADC_CLK` | ADC clock |
| `ADC_CS` | ADC chip select |
| `ADC_DOUT` | ADC serial data |
| `Buzzer` | Buzzer output |
| `SW_zero` | Buzzer enable switch |

The design uses the 100 MHz system clock and is mapped to the FPGA pins through `constraints.xdc`.
